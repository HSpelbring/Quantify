Python Dependencies Installation: (Python 3.10+ Recommended)

cd analytics/src
pip install -r requirements.txt


Go Dependencies Installation: (Go 1.22+ Recommended)

cd backend
go mod tidy


Frontend Dependencies:

Node.js LTS (v18 or v20) 
- install at nodejs.org

Angular CLI
run: npm install -g @angular/cli

Other Dependencies:

cd frontend
npm install


Run Python + Go + Angular:
Run Go Backend: go run cmd/backend/main.go
Run Analytics: python -m uvicorn app:app --reload
Run Angular: ng serve --open

Tilt-dev
- install from github repo scripts
- Run [in root directory]: tilt up 

Unit Tests:
Python - (in /analytics/src) python -m pytest -q
